# Setup

## Prerequisites

- Node.js ≥ 22 (scaffolded on 25.6) and pnpm 10 (`packageManager` is pinned in `package.json`)
- For Dev 2 (Anchor program): Rust, Solana CLI 3.x, Anchor CLI 0.32.1 (via `avm`)
- For Dev 3: a QuickNode Devnet endpoint (RPC + WSS) and the committed IDL from Dev 2
- A Solana Devnet wallet with Devnet SOL; a QuickNode Devnet endpoint (optional at first)

## Install and run

```bash
pnpm install
cp .env.example .env
pnpm dev:api    # GET http://localhost:4000/health
pnpm dev:web    # http://localhost:3000
pnpm typecheck && pnpm lint && pnpm build
```

## Anchor

```bash
anchor build                 # builds the program and regenerates target/idl
anchor test                  # localnet suite (~25 min; deposit-deadline/timeout tests wait on chain time)
cargo test -p escrow         # Rust unit tests (exact time-boundary tests)
pnpm escrow:check            # program ID / IDL / interface readiness (offline); --online reads Devnet
```

Anchor tests need the `[[test.genesis]]` entry in `Anchor.toml` (loads the program as upgradeable with
the provider wallet as upgrade authority, like a real deployment). Devnet deployment, mock mint and
Config initialization: `programs/escrow/docs/DEVNET.md` (not yet deployed).

- The program ID is `E6tFGqHoSUpQmL3U5u8TmYHDJnjdHm8yKk4KifJUt4zr`. Its keypair was generated by
  `anchor build` into `target/deploy/` (gitignored) on the scaffolder's machine. **Dev 2 owns this:**
  either obtain that keypair out-of-band or regenerate and run `anchor keys sync`, then update the
  `.env` values. Never commit keypairs.
- **Cargo.lock is committed and pinned.** Solana's SBF toolchain (platform-tools v1.51) bundles
  Cargo/rustc 1.84, which cannot parse crates using Rust edition 2024. Several transitive
  dependencies were pinned down (`blake3`, `zeroize`, `proc-macro-crate`, `indexmap`,
  `hashbrown`, ...). Avoid a blanket `cargo update`; if a build fails with `feature edition2024
is required`, pin the named crate with `cargo update -p <crate> --precise <older>`.

## Working in parallel

Each developer branches from `main` and edits their own paths (`docs/developer-ownership.md`).
Per-module checks: `pnpm --filter @hedged/solana typecheck` (Dev 3, independent of the API),
`pnpm --filter @hedged/api typecheck` (Dev 4), `pnpm --filter @hedged/web typecheck` (Dev 1),
`anchor build` (Dev 2).

## Environment

See `.env.example`. Server-only values (RPC keys, Gemini, Supabase service role, relayer key path)
must never use `NEXT_PUBLIC_*`.

## Version notes

TypeScript is pinned to 5.9 (typescript-eslint does not yet support 7.x). `@solana/web3.js` is 1.x
because wallet-adapter and Anchor 0.32 require it.
